# Анализ внутриигровой экономики: «Секреты Тёмнолесья»

## Описание проекта
Данный проект представляет собой исследовательский анализ данных (EDA) и решение ad-hoc задач для оценки внутриигровой экономики фэнтези-игры. Главная цель — изучить влияние расы персонажей на покупку премиальной валюты («райские лепестки»), проанализировать распределение стоимости транзакций, выявить аномалии и определить наиболее популярные внутриигровые предметы.

## Стек технологий и навыки
* **Инструменты:** PostgreSQL, DBeaver
* **SQL-навыки:** CTE (WITH), оконные функции (OVER, PARTITION BY), продвинутые статистические функции (PERCENTILE_CONT для расчета медианы, STDDEV для стандартного отклонения), подзапросы, агрегация данных, объединение таблиц (JOIN).

## Данные
Анализ проводился на основе схемы `fantasy`, включающей следующие таблицы:
* `users` — данные о пользователях (статус платящего игрока, id выбранной расы).
* `race` — справочник игровых рас (Angel, Demon, Hobbit, Human, Northman).
* `events` — лог транзакций с указанием стоимости и идентификатора купленного предмета.
* `items` — справочник доступной эпической экипировки.

## Ключевые выводы
1. **Конверсия:** Общая доля платящих игроков составляет около 18%. Выбранная игровая раса не оказывает радикального влияния на готовность пользователя донатить (показатели стабильно держатся в коридоре 17.4% – 19.4%).
2. **Распределение чека:** Наблюдается существенный разрыв между медианной стоимостью покупки (75 лепестков) и средним чеком (526 лепестков). Это свидетельствует о наличии сегмента игроков, совершающих редкие, но крайне дорогие транзакции (вплоть до 486 тыс. лепестков). 
3. **Аномалии:** Выявлено 907 транзакций с нулевой стоимостью (0.07% от общего объема), что требует технической проверки системы логирования событий.
4. **Хиты продаж:** Всего два эпических предмета («Book of Legends» и «Bag of Holding») генерируют абсолютное большинство покупок (76.9% и 20.8% соответственно). Остальные предметы практически не востребованы (29 предметов не покупались ни разу). Маркетинговую стратегию и балансировку магазина рекомендуется строить вокруг этих двух флагманов.
